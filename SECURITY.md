# Security

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/elias4044/spicy-lyrics-desktop/security/advisories/new). Include the affected version, how to reproduce the issue, and its impact. Redact keys and personal data.

Security fixes target the latest release. For ordinary crashes, rendering issues, and feature requests, use [GitHub Issues](https://github.com/elias4044/spicy-lyrics-desktop/issues).
